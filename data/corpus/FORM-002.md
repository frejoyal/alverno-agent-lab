## Utilisation

Ce gabarit sert à documenter l'inspection premier article (IPA) réalisée selon QP-005. Il comprend trois parties : l'identification de la pièce, la vérification des documents et matières, et le relevé des caractéristiques. Lorsque le client impose son propre format de rapport, le format du client est utilisé et le présent gabarit sert de liste de vérification interne.

## Partie A — Identification

| Champ | Contenu attendu |
|---|---|
| Numéro de pièce | Selon le dessin du client |
| Révision du dessin | Par exemple rév. D |
| Spécification client et version | Par exemple SPEC-VRN-01, version 2.0 |
| Motif de l'IPA | Nouvelle pièce, nouvelle révision, changement de procédé, changement de fournisseur, arrêt de plus de 12 mois, exigence du client |
| Type d'IPA | Complète ou partielle (partielle : autorisation du responsable qualité) |
| Numéro de lot et de pièce inspectée | Identification de la pièce IPA |
| Numéro de série de la pièce IPA | S'il y a lieu |

## Partie C — Relevé des caractéristiques

Une ligne par caractéristique numérotée sur le dessin ballonné. **Toutes les caractéristiques** doivent être relevées.

| N° | Caractéristique | Nominal | Tolérance | Mesuré | Instrument (EQ-NNNN) | Conforme (C / NC) |
|---|---|---|---|---|---|---|
| 1 | | | | | | |
| 2 | | | | | | |
| 3 | | | | | | |

Pour une caractéristique non mesurable (note, couleur, texture), inscrire le moyen de vérification (comparaison à l'échantillon, examen visuel).

## Partie D — Résultat

- [ ] IPA acceptée : toutes les caractéristiques sont conformes.
- [ ] IPA refusée : au moins une caractéristique non conforme ; numéro de NC ouverte selon QP-003 :

## Partie E — Signatures

- Réalisée par : le technicien qualité (titre de poste et date)
- Approuvée par : le responsable qualité (titre de poste et date)
- Transmise au client le : (au moins 5 jours ouvrables avant l'expédition du premier lot, si exigé)
- Approbation du client reçue le : (si exigée par la spécification client)

Rappel : la production en série ne commence qu'après l'approbation de l'IPA.
